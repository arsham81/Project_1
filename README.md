# ԶՄՄԿ պլանների համեմատություն

Երկու Excel ֆայլից՝ համեմատական գրաֆիկներ և ցուցանիշների աղյուսակ։

## Գործարկում

Պահանջվում է Python 3.10 կամ ավելի նոր տարբերակ։

```bash
cd /workspace/Project_1
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

Windows-ում՝ `python -m venv .venv`, ապա `.venv\Scripts\python -m pip install -r requirements.txt` և `.venv\Scripts\python app.py`։

Արագ գործարկում՝ Windows-ում `start.bat`, Linux/macOS-ում `./start.sh`։ Առաջին գործարկմանը պահանջվում է ինտերնետ՝ կախվածությունը տեղադրելու համար։

Բրաուզերում բացեք `http://127.0.0.1:8501`։ Ընտրեք բազային և թարմացված `.xlsx` ֆայլերը, ապա սեղմեք «Համեմատել ֆայլերը»։ Ֆայլերի հերթականությունն ընտրում է օգտատերը։

## Հնարավորություններ

- Պղնձի, մոլիբդենի, վերամշակման և արդյունահանման համեմատական գրաֆիկներ։
- Պղնձի փոփոխության գործոններ՝ ծավալ, պարունակություն, կորզում։ Կորզման ազդեցությունը հաշվարկվում է արտադրությունից բխող տարեկան կորզմամբ, որը կարող է տարբերվել Excel-ի միջին կորզումից։
- Փաստի և պլանի բաժանում՝ երբ ամսական գումարը համապատասխանում է տարեկան ցուցանիշին։
- Բոլոր համադրելի հիմնական ցուցանիշների աղյուսակ, աղբյուր բջիջներ։
- SVG գրաֆիկների և CSV աղյուսակի ներբեռնում, բրաուզերով տպում/PDF պահպանում։

Աջակցվում են տրամադրված ԶՄՄԿ V1.6.1, V1.7.2, V2.1, V3.2 և V3.3.6 կառուցվածքները։ Թերթը և տարեկան սյունակը որոշվում են վերնագրերով, տողերը՝ ռուսերեն ցուցանիշների անուններով։ Այլ կառուցվածքով ֆայլերը կարող են պահանջել համապատասխանեցում։

Օգտագործվում են Excel-ում պահպանված հաշվարկված արժեքները. բանաձևերը չեն վերահաշվարկվում։ Եթե արժեքները բացակայում կամ հնացած են, նախ ֆայլերը վերահաշվարկեք և պահպանեք Excel-ում։ Ֆայլերը չեն պահվում սերվերի սկավառակին և չեն ուղարկվում արտաքին ծառայությունների։ Ֆայլի առավելագույն չափը՝ 20 ՄԲ։

Սերվերը լռելյայն հասանելի է միայն տեղական համակարգչից։ Սա տեղական վերլուծական գործիք է՝ առանց մուտքի կառավարման. մի հրապարակեք այն անմիջապես ինտերնետում։ `PORT` փոփոխականով կարելի է փոխել պորտը։
