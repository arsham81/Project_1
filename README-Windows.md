# Windows · Desktop պատկերակով ծրագիր

1. Ներբեռնեք և ամբողջությամբ բացեք ZIP-ը՝ **Extract All**։ Մի գործարկեք տեղադրումը ZIP-ի ներսից։
2. Բացեք ստացված պանակը և գործարկեք **install.bat**։
3. Առաջին տեղադրմանը պահանջվում են ինտերնետ և **Python 3.10+**։ Եթե Python չկա, կբացվի պաշտոնական ներբեռնման էջը. տեղադրեք Python-ը՝ ընտրելով **Add Python to PATH**, ապա կրկին գործարկեք install.bat։
4. Տեղադրումից հետո Desktop-ում կստեղծվի **ZCMC Plan Compare** պատկերակը։ Հետագա գործարկումների համար օգտագործեք հենց այն։
5. Ծրագրում ընտրեք բազային և թարմացված երկու Excel ֆայլերը, սեղմեք ստեղծման կոճակը և ընտրեք արդյունքների պանակը։
6. Ստեղծվում են **ZCMC_comparison.xlsx** և **ZCMC_comparison.pdf**՝ նոր առանձին պանակում։ Excel-ը պարունակում է թվային աղյուսակ, աղբյուր բջիջներ և գրաֆիկներ։ PDF-ը՝ նույն գրաֆիկներն ու համեմատական աղյուսակը։

Մուտքային Excel ֆայլերը չեն փոփոխվում։ Դրանք չեն ուղարկվում ինտերնետ։ Տեղադրումից հետո հիմնական աշխատանքն ինտերնետ չի պահանջում։ Microsoft Excel-ի տեղադրված լինելը պարտադիր չէ հաշվետվությունները ստեղծելու համար։

Սա Python-ով աշխատող Windows ծրագիր է՝ տեղադրման սցենարով և Desktop պատկերակով, ոչ ստորագրված .exe տեղադրիչ։ Եթե համակարգչի կազմակերպության քաղաքականությունն արգելափակում է սցենարների գործարկումը, դիմեք ադմինիստրատորին։ Մի անջատեք պաշտպանությունը։

Տեղադրման տեղը՝ `%LOCALAPPDATA%\ZCMCPlanCompare`։ Թարմացնելու համար նոր ZIP-ը բացեք և կրկին գործարկեք install.bat (այդ պահին ծրագիրը պետք է փակ լինի)։ Հեռացնելու համար ջնջեք այդ պանակն ու Desktop պատկերակը։ Արդյունքների ֆայլերը առանձին են և պահպանվում են։

Աջակցվում են տրամադրված ԶՄՄԿ 2026-ի պլանների ձևաչափերը։ Excel-ի բանաձևերը չեն վերահաշվարկվում. օգտագործվում են ֆայլում պահպանված արժեքները։ Եթե տվյալները հնացած են, ֆայլերը նախ վերահաշվարկեք և պահպանեք Excel-ում։
